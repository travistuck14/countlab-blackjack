CountLab Blackjack — iPhone installable web app

This package must be hosted on an HTTPS website to install as an app. Easiest free option: GitHub Pages.

1. On a computer, create a GitHub repository (or use one you own).
2. Upload index.html, manifest.webmanifest, sw.js, and icon.svg to the repository root.
3. In repository Settings > Pages, enable deployment from the main branch and root folder.
4. Wait for GitHub Pages to publish the site. Open the HTTPS Pages URL on your iPhone in Safari.
5. Tap Share > Add to Home Screen. If offered, turn on Open as Web App, then tap Add.

Once installed, it opens in an app-like full-screen window and can work offline after the first successful load.
This is a web app, not an App Store-native app.
